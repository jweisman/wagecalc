# Wage Calculator

This simple app is meant to help wth a household pain point - calculating hourly wages for cleaning people, etc.

## Main Screen
Main elements:
* Hourly rate (persists across sessions)
* Start time (button for "now")
* End time (button for "now")
* Wage
* Clear button

Workflow:
* Clear button
* Set start time when worker arrives (persist)
* Set end time when worker is finished
* Wage is shown

## Preferences
* Format (currency & time) - default device locale
* Time intervals (default to 15 minutes, options 5, 10, 15, 30, 60)
* Theme (device, light, dark)

## UX
* Large interface
* iOS Stopwatch vibes
